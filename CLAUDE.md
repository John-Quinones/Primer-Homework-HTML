# Project memory — TecjuridicosApp (formerly JuanMaApp; TEC Jurídicos)

The app lives in `juanmaapp/`. The other files at the root are unrelated homework.

## Who and how
- Client: TEC Jurídicos, Colombia; main office Ibagué (Tolima). The app is named "TecjuridicosApp" (renamed from JuanMaApp in change 18); internal identifiers (folder juanmaapp, Azure juanmaapp-tec, window.Juanma*, storage keys) keep the old name on purpose.
- Talk to the user in Spanish. UI text is Spanish (Colombia); code and comments are English.
- Brand: navy `#002b6a`, blue `#027cc6`, silver `#989795`, light silver `#c4c8cb`; "T" column logo (`public/logo-t.png`). Layout follows appbogado.app with these colors.
- Drafting engine: `prompts/nomosai-system-prompt.md` (NomosAI: no AI clichés, `[FILL: …]` markers, audit footer, Bold link, e-signature block, JSON payload). `src/validate.js` enforces it.

## Never
- Never show invented data (fake cases, judgments, actuaciones). If something needs the internet or e-mail and is not available, say so in the UI.
- Never reset the user's stored data. Data structure changes are migrations (`src/db.js` `migrate()`, `public/demo-backend.js` `migrate()`); the browser storage key in `public/web-store.js` never changes.

## Decisions to keep
- Receipts are numbered consecutively from 1155 (`RECEIPT_START`, adjustable upward in Ajustes de cobro, never backwards).
- Payment reminders follow Ley 2300 de 2023 (`collectionWindow` in `src/ledger.js`, Colombian holidays included).
- Contract fees = the case's charges in Pagos (`{{honorarios.*}}`, `feeVariables`).
- Signed PDFs (stamps + certificate) are built by `public/pdf-tools.js`, also on the server via `src/signed-pdf.js`.
- Certified e-mail keeps the exact .eml with SHA-1/256/512/SHA3-512, every opening/download/acknowledgment in `mail_events`, optional RFC 3161 stamp (`src/tsa.js`, TSA_URL). It is evidence, not an ONAC-accredited certified e-mail service.

- E-mail on Azure goes through Microsoft 365 / Graph (MAIL_TRANSPORT=graph, MAIL_FROM, Exchange RBAC for Applications); WhatsApp uses templates tecjuridicos_aviso (utility) and tecjuridicos_codigo (authentication). SMS is not used (user asked to omit it). Steps in juanmaapp/AZURE.md 6–7.
- Signed PDFs are generated once and kept with their SHA-256; verification in Firmas and public verificar.html (code on every page).
- The starter contract is numbered with the case folder ({{expediente.carpeta}}).
- Client and case screens (`#cliente-ID`, `#expediente-ID`, changes 46–47): the case screen gathers tasks per funcionario with follow-up (`taskFollowUp` in `src/case-meta.js`), oficios/peticiones/requerimientos with delivery and answer, all actuaciones with one-click consult, and the full history. Task kinds: `TASK_KINDS`; petitions 15 business days (`addBusinessDays`).
- Parties (change 49): `cases.parties` JSON list {side activa|pasiva, name, id_number, ours, client_id}; our clients linked by document see the case. Nothing opens on a stray click: only "Ver …" buttons (`data-action="go"`, routes `#expediente-ID-section`).
- Audit log (change 50): `src/audit.js` middleware logs every API change (who, Colombia time, device from User-Agent, IP, field diff via `auditDiff`); auth events logged explicitly. View «Bitácora» needs `audit.view`. Never edited or deleted. Demo mirrors it in `s.audit` (last 5000).
- Security (change 51, OWASP audit): scrypt2 hashes (N=2^17, rehash on login; tests set SCRYPT_LOG_N), `auth_throttle` table per e-mail and IP, idle sessions (`last_seen`), `users.ms_oid` binding, `publicBase()` for mailed links, CSP header (no inline scripts: page code in `*-page.js`), `inTransaction()`. Options PASSWORD_LOGIN=off, SESSION_IDLE_HOURS, SETUP_TOKEN. Weak passwords (name/e-mail inside, digits only) are refused: test passwords avoid the user's name.
- Case responsible (version 2.12): panel «Funcionario responsable» on the case screen (`responsiblePanel`, actions `set-responsible`/`clear-responsible`/`task-for`) sets `cases.assigned_user_id` with a partial PUT and opens the task dialog with `preset.assigned_user_id`; pickers use `caseStaff(officeId)` and `staffLabel` (hidden users = «Asistente»).
- Client names are buttons (`clientName()`, `data-client-menu`) opening a menu with the client's data and cases (change 52); side-menu links carry a description (`NAV_DESC`).

- Legal documents and client authorizations (change 56): texts in `src/legal.js` (shared as `window.JuanmaLegal`; firm data in `FIRM`, empty = [COMPLETAR]; version = App version via `legalVersion()`/`setLegalVersion(VERSION)`, user's rule). Demo mirrors it in `s.consents` (no link sending). Public page `legal.html`.
